    ```html
    <!doctype html>
    <html lang="en">
      <head>
        <script>(function(){var t=localStorage.getItem('mmess.theme')||'system';var r=t==='system'?(matchMedia('(prefers-color-scheme:dark)').matches?'dark':'light'):t;document.documentElement.dataset.theme=r;})();</script>

        <meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover" />

      </head>
      <body>
        <div id="root"></div>
        <script type="module" src="/src/main.tsx"></script>
      </body>
    </html>
    ```

    **3. Generate PWA icon PNGs using sharp** (already installed as a project dependency):

    Create a temporary script `scripts/gen-icons.mjs` and run it:

    ```javascript
    import sharp from 'sharp';
    import { mkdirSync } from 'fs';

    mkdirSync('client/public', { recursive: true });

    const svgContent = (size) => Buffer.from(`<svg xmlns="http://www.w3.org/2000/svg" width="${size}" height="${size}" viewBox="0 0 ${size} ${size}">
      <rect width="${size}" height="${size}" fill="#0b57d0"/>
      <text x="${size/2}" y="${size/2}" font-family="system-ui, -apple-system, sans-serif"
            font-size="${Math.round(size * 0.39)}" font-weight="700" fill="#ffffff"
            text-anchor="middle" dominant-baseline="central">mm</text>
    </svg>`);

    await sharp(svgContent(192)).png().toFile('client/public/icon-192.png');
    await sharp(svgContent(512)).png().toFile('client/public/icon-512.png');
    console.log('Icons generated: icon-192.png, icon-512.png');
    ```

    Run with: `node scripts/gen-icons.mjs`

    After generation, delete `scripts/gen-icons.mjs` (it is a one-shot tool, not a committed artifact).
    Note: If sharp's SVG rasterization fails (missing librsvg on the host), fall back to writing minimal 1×1 placeholder PNGs and note in the SUMMARY that icons need regeneration on Linux/Mac where librsvg is available. The manifest must still be committed and functional.

```typescript
export const files = pgTable('files', {
  id: uuid('id').primaryKey().default(sql`gen_random_uuid()`),
  uploader_id: uuid('uploader_id').notNull().references(() => users.id, { onDelete: 'cascade' }),

  storage_name: varchar('storage_name', { length: 255 }).notNull().unique(),
```

Two new columns needed:
- `thumbnail_path: text('thumbnail_path')` — nullable, null for non-images
- `conversation_id: uuid('conversation_id').references(() => conversations.id, { onDelete: 'set null' })` — nullable, set when file attached to a message

messages.file_id currently:
```typescript
file_id: uuid('file_id'), // references files.id — set after files table
```
Needs to become:
```typescript
file_id: uuid('file_id').references(() => files.id, { onDelete: 'set null' }),
```
NOTE: This requires files table to be defined BEFORE messages table in schema.ts, or use a forward-reference with lazy evaluation. Use `.references(() => files.id)` with arrow function (Drizzle supports forward refs).

Remove this entire block:

Add this block BEFORE the existing `handle /api/*` block (Caddy evaluates in definition order — more specific first):
```
# ── File API — explicit body size limit for uploads (D-18 revision) ──────

    uri strip_prefix /api
    reverse_proxy api:3000
}
```

  <behavior>
    POST /auth/register:
    - Check users count: if 0, skip invite check and set role/admin marker; if > 0, require valid invite token
    - Validate invite: hash the provided token with SHA-256, find invite row where token_hash matches, not yet used, not expired
    - Create user with argon2.hash(password, { type: argon2id, memoryCost: 19456, timeCost: 2, parallelism: 1 })
    - Mark invite used_by = new user id, used_at = now (in same transaction)
    - Return 201 with { ok: true }

    POST /auth/login:
    - Look up user by email, call argon2.verify(password_hash, password)
    - On success: issue access JWT (sub, username, 15m), generate nanoid(32) refresh token, hash it SHA-256
    - Insert into sessions: user_id, token_hash, device_label (parseUserAgent), user_agent (raw UA string), ip_address (request.ip), last_seen_at (now), expires_at (now + 30 days)
    - Set access_token cookie (path='/', httpOnly, SameSite=Lax, Secure=prod, maxAge=900)
    - Set refresh_token cookie (path='/api/auth/refresh', httpOnly, SameSite=Lax, Secure=prod, maxAge=2592000)
    - Return { ok: true }

    POST /auth/refresh:
    - Read refresh_token cookie; if missing → 401
    - SHA-256 hash it, SELECT ... FOR UPDATE inside Drizzle transaction
    - If not found or expired → 401
    - Rotate: generate new nanoid(32), hash, update sessions row (new token_hash, last_seen_at=now, rolling expires_at=now+30d)
    - Re-issue new access JWT and set both cookies (new refresh_token cookie too)
    - Return { ok: true }

    POST /auth/logout (requires authenticate):
    - Read refresh_token cookie, hash it, DELETE matching sessions row
    - clearCookie('access_token', { path: '/' })
    - clearCookie('refresh_token', { path: '/api/auth/refresh' })
    - Return { ok: true }
  </behavior>

    **server/src/routes/auth/sessions.ts:**
    Register two routes under a single plugin:
    ```typescript
    // GET /auth/sessions
    fastify.get('/auth/sessions', {
      preValidation: [fastify.authenticate],
    }, async (request, reply) => {
      const userId = request.user.sub;
      const currentRefreshRaw = request.cookies['refresh_token'];
      const currentHash = currentRefreshRaw
        ? createHash('sha256').update(currentRefreshRaw).digest('hex')
        : null;

      const rows = await db.select().from(sessions)
        .where(eq(sessions.user_id, userId))
        .orderBy(desc(sessions.last_seen_at));

      return rows.map(s => ({
        id: s.id,
        device_label: s.device_label ?? 'Unknown device',
        ip_address: s.ip_address,
        created_at: s.created_at,
        last_seen_at: s.last_seen_at,
        isCurrentDevice: s.token_hash === currentHash,
      }));
    });

    // DELETE /auth/sessions/:id
    fastify.delete('/auth/sessions/:id', {
      preValidation: [fastify.authenticate],
    }, async (request, reply) => {
      const { id } = request.params as { id: string };
      const userId = request.user.sub;

      const [session] = await db.select().from(sessions)
        .where(and(eq(sessions.id, id), eq(sessions.user_id, userId)));

      if (!session) return reply.code(404).send({ error: 'Session not found' });

      // D-18: block termination of current session
      const currentRefreshRaw = request.cookies['refresh_token'];
      if (currentRefreshRaw) {
        const currentHash = createHash('sha256').update(currentRefreshRaw).digest('hex');
        if (session.token_hash === currentHash) {
          return reply.code(400).send({ error: 'Cannot terminate current session. Use logout instead.' });
        }
      }

      await db.delete(sessions).where(eq(sessions.id, id));
      return { ok: true };
    });
    ```

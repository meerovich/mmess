**NewChatModal.tsx** — DM creation (CONV-01):

Props: `{ onClose: () => void }`.

State:
- `query: string` — search input value
- `results: { id: string; username: string; email: string; avatar_url: string | null }[]` — search results
- `isSearching: boolean`

Behavior:
1. Input: `GET /api/users?q=${query}&limit=20` debounced 300ms on each keystroke
2. Results list: avatar (sm) + username. Clicking an item:
   - Calls `POST /api/conversations` with `{ type: 'direct', participant_ids: [user.id] }`
   - On success: dispatch `UPSERT_CONVERSATION` with returned conversation, dispatch `SET_ACTIVE_CONVERSATION`
   - Call `onClose()`
3. Empty query: show empty results (no API call for q < 2 chars)
4. Empty results: "No users found" / "Try a different name or email."

Accessibility (UI-SPEC): `role="dialog"`, `aria-modal="true"`, `aria-labelledby="new-chat-title"`. Focus trap (Tab cycles within modal). Escape closes.

CTA text: "Open chat" (per UI-SPEC Copywriting Contract).

Modal overlay: fullscreen fixed overlay `rgba(0,0,0,0.4)`. Modal content: centered, white bg `--color-surface`, padding `--space-md`, border-radius 12px, max-width 480px.

NewChatModal.module.css: `.overlay { position: fixed; inset: 0; background: rgba(0,0,0,0.4); display: flex; align-items: center; justify-content: center; z-index: 100; }`.

**NewGroupModal.tsx** — Group creation (CONV-02):

Props: `{ onClose: () => void }`.

State:
- `groupName: string`
- `selectedUsers: Array<{ id: string; username: string }>` — chips
- `query: string` + `results` (same user search as NewChatModal)

Behavior:
1. Group name input: required, max 100 chars
2. User search: same `GET /api/users?q=` debounced 300ms, results show users not already selected
3. Clicking a result user: adds to selectedUsers as a removable chip (× button to remove)
4. "Create group" button: disabled when `!groupName.trim() || selectedUsers.length === 0`
5. On submit: `POST /api/conversations` with `{ type: 'group', name: groupName.trim(), participant_ids: selectedUsers.map(u => u.id) }`
6. On success: dispatch `UPSERT_CONVERSATION`, dispatch `SET_ACTIVE_CONVERSATION`, call `onClose()`

Copywriting (UI-SPEC): "New group" header, "Create group" button.

Accessibility: same as NewChatModal — `role="dialog"`, `aria-modal="true"`, focus trap, Escape closes.

Selected users display: horizontal flex row of chips with name + × button. Chips use `--color-accent-muted` bg.
